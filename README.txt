# Logo Result Gallery

Template gallery logo modern, tanpa login/database.

## Cara menambah logo

1. Masukkan file PNG/JPG ke folder `images`.
2. Buka `script.js`.
3. Tambahkan item di array `results`, contoh:

{ title: "Chisa Wuwek", image: "images/chisa-wuwek.png" }

4. Upload project ke GitHub lalu import ke Vercel.

## Deploy ke Vercel

- Buat repository GitHub baru.
- Upload semua isi folder ini.
- Di Vercel pilih "Add New Project" lalu pilih repository.
- Framework tidak diperlukan. Deploy sebagai static site.

Tidak ada backend, login, database, atau password.
